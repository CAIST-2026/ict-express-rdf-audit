# Mini ICT KG experiment

This is a deterministic, synthetic proof-of-concept generated from controlled Chinese/English device, alarm, and service labels. It is not real operator, vendor, or field data and does not estimate deployment performance. The 60 bilingual queries are evaluated against the same graph under complete mappings and under an intervention that removes or redirects mappings. The script, seed, graph, entity manifest, mappings, query set, and query-level outcomes are retained.

Run: `python3 run_mini_ict_kg.py` (requires rdflib).
